## 🏦 Projeto Alliance Bank – {reprograma}

Este projeto está sendo desenvolvido como parte do curso de **Back-end** da [{reprograma}](https://reprograma.com.br). A proposta é construir a estrutura de um banco digital fictício, com funcionalidades como abertura de contas, operações bancárias e histórico de transações, utilizando um banco de dados para persistência.

> ⚠️ **Projeto em desenvolvimento**: ainda estou finalizando algumas funcionalidades e melhorias.

### 💡 Funcionalidades previstas:
- Cadastro de clientes e contas bancárias
- Depósitos, saques e transferências entre contas
- Consulta de saldo e histórico de transações
- Validações de entrada e tratamento de erros
- Integração com banco de dados (MongoDB)

### 🛠️ Tecnologias utilizadas:
- Node.js
- Express
- JavaScript
- MongoDB + Mongoose
- UUID
- Nodemon
